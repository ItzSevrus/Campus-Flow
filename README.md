# CampusFlow — Responsive University Homepage

## Run it
1. Keep `index.html`, `style.css`, and `script.js` in the same folder.
2. Open `index.html` in a browser, or open this folder in VS Code and run it with Live Server.

## Included
- Responsive desktop, tablet, and mobile layouts
- CSS Grid, Flexbox, relative units, and media queries
- Mobile navigation menu and demo interest form
- Images loaded from Unsplash and fonts from Google Fonts

Images are hotlinked, so an internet connection is required. Unsplash license: https://unsplash.com/license. Check the current license and individual image details before publishing. Replace the fictional university name, sample statistics, and demo form before using this as a real site.
